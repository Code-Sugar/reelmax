# Reel Max · Flutter

根据[原型网站](https://reel-max-mobile-prototype.ryan91james9008.chatgpt.site/)的公开 CSS、交互脚本和原始资源实现。
全部页面为 Flutter 组件，支持 Android、iOS 和 Web。

## 运行

环境：Flutter 3.35.7 / Dart 3.9.2 或兼容版本。

```sh
flutter pub get
flutter run -d chrome
# Android：先连接设备，flutter devices 查看设备 ID
flutter run -d emulator-5554
```

## 已实现

- 启动页：深色灰绿光晕、玻璃播放标识与 Reel Max 字标，约 1.1 秒入场后淡入首页；预加载首张封面，资源失败或超时仍可进入，不在返回应用或切换标签时重播。Android 原生启动画面采用同色底和同款标识。
- Today：视频背景、三种筛选、Next 卡片放大切换、向右收起、全屏跟手上下切换作品（Next 展开时也可滑动）。
- 分类：历史、类型标签、重叠推荐海报、热门、横滑影院卡片。
- List：History / Collect、观看进度、编辑移除、左滑显示 Delete、空列表。
- Search：实时筛选、清空搜索、趋势列表，点击结果进入对应详情。
- 个人中心：第四个底栏入口，游客／登录状态、会员卡、金币余额、充值、订单记录与详情、金币流水、退出登录；搜索移至首页和个人中心顶部。
- 登录：邮箱登录、注册、找回密码与演示验证码重设、Google／Facebook 示例账号登录，包含表单校验和密码显隐。
- 商店与支付：月度／年度会员、四档金币包、结算方式选择、购买成功页；购买后联动余额、订单、金币流水及会员剧集权限。
- 应用语言：中文／英文即时切换，覆盖新增页面与原有主要菜单；剧名和演示内容保留原文。
- 详情：按所选剧目显示标题、封面和简介，固定演员与推荐内容、03–05 选集入口，点赞状态按剧目保存，支持 Trailer、返回按钮和系统返回；不支持拖拽关闭。
- 播放器：本地视频、暂停、全屏跟手上下切集、短拖回弹、播完下一集、进度拖动、点赞和黄色收藏反馈；剧集面板显示 1–20 集（前 5 集可选），清晰度可选 720p／1080p／2K／4K。
- 原版 56 个资源本地化；Commissioner 可变字体、SVG 图标、玻璃模糊、渐变和过渡动画。
- 玻璃按控件单独调校：内高光、内阴影、背景色彩滤镜、底栏局部反射，外阴影不污染透明表面。
- 各页顶部统一适配系统安全区，首行距状态栏下缘 12px；页面进入／返回为 320／240ms，标签切换为 280ms。

日常操作通过画面、选中状态和列表变化反馈，不弹底部气泡；邮箱／密码校验和剧集未解锁等必要说明保留。分区“更多”、评分等未接入的演示入口不再弹占位提示；演示数据与状态不需要后端。
剧目卡片已按后续需求改为进入详情，覆盖首页、分类、列表和搜索。
详情暂用固定演示简介、演员和推荐海报填充下方内容；选集播放现有三段本地演示素材。
播放器前 5 集免费可选，第 6–20 集默认锁定，演示订阅生效后全部可选；20 集复用三段演示视频。清晰度暂保存选择并更新按钮，不切换视频源，1080p 图标单行自适应缩放。面板关闭后保留进度与播放／暂停状态。

## 账号与支付演示范围

- 按用户确认，本次为完整本地演示流程，不连接邮箱、Google／Facebook OAuth 或支付服务；所有美元价格均为演示价格，不扣款。
- 新注册账号赠送 100 金币；邮箱登录和社交示例账号初始有 120 金币及示例记录，便于预览页面。购买金币及赠送部分分别写入流水。
- 找回密码使用界面明确展示的演示验证码 `123456`，只演示校验与完成状态；不会发送邮件，不保存或验证账号密码。
- 账号、余额、订单、会员和语言保存在当前进程内存中；退出后重新登录同一邮箱可恢复本次运行的数据，不同邮箱数据隔离，重启应用后重置。不保存密码、OAuth 令牌或支付凭据。
- 后续接真实服务时需替换账号状态与购买实现，并接入服务端订单验证、持久化和真实会员权益。
具体尺寸、交互映射和验证限制见 [反推记录](reference/IMPLEMENTATION.md)。

## 验证与构建

```sh
flutter analyze
flutter test
flutter drive --driver=test_driver/integration_test.dart --target=integration_test/app_test.dart -d emulator-5554
flutter build web --release --no-web-resources-cdn
flutter build apk --debug --split-per-abi
```

Widget 测试截图输出至 `build/verification/`；集成测试输出 `android-*.png`。
Widget 截图用原视频的固定帧替换平台纹理，Android 集成测试使用真实视频解码。
手机 APK 位于 `build/app/outputs/flutter-apk/app-arm64-v8a-debug.apk`；
x86 模拟器使用同目录的 `app-x86_64-debug.apk`，Web 构建位于 `build/web/`。
当前模拟器运行通用包时发生 ARM 转译崩溃，因此分别提供手机 ARM64 包和模拟器 x86_64 包。
iOS 工程已生成，需在 macOS / Xcode 环境编译验证。

当前根据源码精确参数进行还原，尚未完成原型与 Flutter 的浏览器逐像素比对；不同平台的文字抗锯齿、玻璃滤镜和系统安全区可能存在差异。
