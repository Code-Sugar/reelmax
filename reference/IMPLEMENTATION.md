## 品牌启动页

- 复用现有灰绿／炭黑色系和 Commissioner 斜体字标，以 80px 播放标识和留白作为视觉中心；原生首帧与 Flutter 首帧的标识位置、尺寸及底色一致，随后标识上移、字标和副标题依次显现。
- 入场 1100ms，离场 360ms；同时预加载首页封面，首页视频在遮罩后自行初始化。入口不依赖网络或视频准备，预加载失败继续，超过 2 秒仍未完成则放行。没有虚构进度或广告倒计时。
- 启动期间屏蔽首页点击、焦点和无障碍内容；完成后移除遮罩但保留原首页实例。回到前台和切换主标签不重播，系统减少动画设置会跳过品牌动画。
- Android 配置按 [Flutter 启动页文档](https://docs.flutter.dev/platform-integration/android/splash-screen) 与 [Android SplashScreen 文档](https://developer.android.com/develop/ui/views/launch/splash-screen) 实现；覆盖亮／暗系统主题及 Android 12+ 图标配置，普通窗口背景也设为同色。
- iOS LaunchScreen 同步改为深色原生底，移除模板启动图；此处在 Windows 仅检查 XML，仍需 macOS / Xcode 验证。Web 已有同色 HTML 背景，共用 Flutter 启动页。
- MuMu Android 12 桌面图标冷启动已实测：原生播放标识 → Flutter 品牌动画 → 首页，截图保存在 `build/verification/startup-launcher/`。命令行直接启动 Activity 时，模拟器的系统启动阶段仅显示深色背景，因此原生图标验收以桌面入口为准。
- 回归覆盖正常预加载、超时和失败放行、输入屏蔽、首页实例保留、前后台不重播、提前销毁、减少动画及 390×844／360×640 截图，输出 `build/verification/startup-*.png`。

## 玻璃材质校正

- 筛选、Play、底栏和底栏选中项分别使用原型 CSS 的渐变、模糊和反光参数。
- 使用背景模糊及饱和度／亮度矩阵；文字、图标不经过滤镜。
- 按 CSS 角度计算渐变端点，避免长胶囊的渐变方向随宽高比例失真。
- 绘制顶部内高光、底部内阴影、斜向反射，以及底栏的径向高光和柔和青色反光。
- 外阴影只画在轮廓之外，避免普通 BoxDecoration 阴影填充控件内部，使透明玻璃发暗。
- 截图测试启用真实软阴影，并增加 Top／Redline 状态；Android 截图为 `android-today-redline.png`。

## 顶部间距与转场调整

按用户后续反馈，六个页面的首行统一放在状态栏安全区下方 12 个逻辑像素。
Web／桌面模拟状态栏预留 36px，手机直接采用系统安全区。
固定标题区域随顶部间距同步缩短，不留下额外空白。
页面进入／返回改为 320／240ms，底部标签切换 280ms，首页作品和播放器切集 360ms。

## 保留的原型行为

- New / Top / Exclusive、类型筛选只更新选中状态，不改变演示数据，也不弹操作提示。
- 第四个底栏按钮按后续需求改为个人中心，首页和个人中心顶部的放大镜均打开搜索路由。
- 保留原型 `Popular Tpday` 拼写；评分、分类分区的“更多”等未接入的入口禁用操作，不再显示占位提示。院线横向翻页保留实际滚动行为。
- 播放器 List 和清晰度按钮按后续需求改为底部选择面板；本地仍没有多码率视频，清晰度选择只更新当前会话状态与按钮。
- 列表 History / Collect 切换时重置本标签删除记录；离开主标签后页面状态重置。
- 播放器收藏状态与 List 的固定演示数据互相独立。
- 视频全部静音，首页循环，播放器播完自动进入下一集并循环可播放剧集；默认 01–05，演示会员为 01–20，均复用现有三段视频。

## 剧目详情导航调整

- 首页当前作品、分类页所有海报及推广卡、列表 History / Collect、搜索结果统一传递 DramaInfo 进入详情。
- 标题、封面、已有简介及首页预览视频跟随所选剧目；首页剧目补全固定演示简介，其他无简介条目使用固定演示文案。演员和推荐海报按后续需求恢复为静态演示内容，播放器继续使用现有演示视频。
- 点赞按剧目标题与封面形成的标识独立保存；同一剧目从不同入口进入时共享点赞状态。
- 删除详情页的原始指针拖拽、位移缩放及下拉关闭逻辑。内容照常滚动，返回按钮和系统返回回到原页面并保留滚动位置／搜索词。
- 推荐海报超出背景卡片的部分已纳入点击区域。
- 回归测试逐一访问 30 个剧目入口，并覆盖海报底部点击、点赞隔离、系统返回与斜向拖动不关闭。

## 详情内容与全屏滑动修复

## 个人中心与购买演示

- 新页面按设计反馈重新排版：沿用分类页 24px 斜体品牌字、Commissioner 字体、炭黑／灰绿背景；主按钮直接复用首页 Play 玻璃材质，次按钮复用筛选胶囊。金色仅用于金币和奖励，不作为会员整块背景。
- 个人中心采用紧凑账号区、176px 影视会员横幅、钱包和三行功能列表。游客状态下订单、金币记录与语言入口在常见手机首屏内可见；登录和会员信息增加时可向下滚动，底部预留导航安全空间。
- 登录用原有影视剧照，会员横幅复用现有海报；不增加新图片依赖。Google／Facebook 并排显示，邮箱表单独立分组；注册和找回密码使用简洁标题。
- 会员套餐以横向价格行呈现，金币包采用轻描边网格；页签沿用 List 的文字加短下划线，支持横向滚动避免长标签换行。订单与金币记录减少重复标题和卡片嵌套。

- 月度会员 $9.99、年度会员 $59.99；金币包为 300／1,000／2,500／6,000，后三档赠送 100／500／1,500，价格分别为 $2.99／$9.99／$24.99／$49.99，全部为演示数据。

## 验证范围与限制

- 已移除普通操作的全局气泡及播放器定时手势提示：手动／自动切集、指定选集、筛选切换、Next 展开收起、列表编辑和删除均只更新界面。邮箱／密码表单校验、锁定剧集说明、视频加载失败信息与登录／支付必要流程保留。

- 播放器收藏使用黄色实心书签、玻璃描边、弹跳和同色粒子，取消时恢复白色轮廓。
- Episodes 面板显示 01–20，默认 01–05 可选、06–20 上锁，演示会员生效后全部可选；当前集高亮，点击锁定项显示提示，不关闭面板或开始播放。
- Quality 面板提供 720p／1080p／2K／4K，重新打开保留选中项，右侧按钮同步显示。此处仅为选择交互，不宣称改变实际视频分辨率。
- 面板打开暂停当前视频，关闭后恢复原有播放状态；选择清晰度不重置进度，选择不同剧集从头播放。遮罩、关闭按钮和系统返回均可关闭面板。

- Widget 测试执行完整交互链路，并输出 390×844、360×740 和桌面布局截图。
