# 接口接入与原设计保留

## 原则

接口只填入现有组件，不根据接口返回结构重新设计页面。缺少字段或对应区块时保留原固定内容，等后端补充后再替换。

## 分类页

复用 `CategoryPage`：History、Explore Genres、重叠推荐海报、Hot New、不对称海报、Popular Tpday、Today In Cinemas 与底部推广位均保留。

`skit/init` 按模块标题对应现有区块，不能将无关模块按数组顺序填入。现有海报插槽支持 `recommendations`、`hot new`、`today in cinemas`，不足的插槽继续用固定内容。后端目前的 `test`、`list`、`week` 等模块没有明确对应关系，因此保留这些区块的原素材。历史、分类标签和 Popular Tpday 暂保留固定内容，后续确定接口映射再接入。

## 详情页

复用 `DetailPage` 的背景、顶部爱心/评分、封面、Watch Trailer、简介、演员、剧集与猜你喜欢。

- 接口已有：标题、封面、简介、分类、点赞数/状态、评分、剧集。
- 缺失字段：优先保留进入详情时的数据，其次使用原固定内容。
- 演员与猜你喜欢暂无字段，保留原数据。
- 剧集卡片保持玻璃样式；超过三集时横向滚动。真实剧目播放仍通过真实播放器获取播放地址及权限。

## 缓存

- 底栏按需创建页面并保留在 IndexedStack，保留滚动、筛选和已加载内容；隐藏的首页视频暂停。
- 首页、分类和详情的接口结果在内存缓存五分钟，最多八十项，同请求合并。重开应用不保留此缓存。
- 缓存按登录令牌、语言、请求参数隔离；登录变化、点赞、收藏及解锁成功使缓存失效。请求失败不缓存。
- 金币余额、用户信息、支付及播放授权不走剧目缓存。
- 已打开 Tab 不因切换而重新请求。重新打开详情时优先读有效缓存。
- 播放器页面保留最近三集的已初始化播放器和缓冲，切回时复用原实例及播放位置、清晰度、暂停状态。非当前集暂停。超出三集时释放最久未使用的播放器，但在本播放页保留进度，下次初始化后跳回该位置；退出播放页时释放全部实例。登录账号变化时清除播放缓存。
